## Four Beats

1. **Name the site.** Give the HydroCAD stormwater model a short title before you sketch a basin.
2. **Pin the live catchments.** Keep current basins on the HydroCAD catchment layout and leave unused reaches aside.
3. **Read the hydrograph.** Open HydroCAD hydrograph results before you move a peak that already has a note.
4. **Check the report.** Read the HydroCAD drainage report before you archive a site.
5. **Close the loop.** Clear finished basins so the next HydroCAD visit does not start with a search.

## First Questions

**Does HydroCAD replace every other program?**
No. HydroCAD sits beside the site list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate HydroCAD profile.

**Will HydroCAD feel heavy on an older laptop?**
No. HydroCAD is meant to stay readable during a normal drainage session.

**What should a new user try first?**
One small HydroCAD catchment today, then the same hydrograph results tomorrow.

**Do hydrograph results leave the stormwater model?**
No. HydroCAD hydrograph results stay with the HydroCAD catchment layout on the same drainage report.

**Is HydroCAD only for a finished site?**
No. HydroCAD can hold a single basin while the rest of the civil set stays off the board.

**Does the site need a second file for the report?**
No. HydroCAD keeps the catchments and the hydrographs on this drainage report.

## Who Sits Down at HydroCAD

## Field Note

HydroCAD is easier to trust when the stormwater model stays smaller than the folder it came from. A named site shows what is active, the catchment pins show what you will check today, and the closing note tells the next person which hydrograph changed.

The same loop fits a single basin, a short reach, or a civil desk shared by two people. Open the last HydroCAD stormwater model, finish one catchment, and leave fewer loose sketches than you found.

A review should not have to guess which basin belongs to the open hydrograph. Keep that pair together inside HydroCAD.

## One Real Pass

Pick a site that already has a name. Open it in HydroCAD, keep only those catchments on the stormwater model, and finish one hydrograph you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different site and leave it out of this HydroCAD drainage report.
